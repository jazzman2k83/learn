Plain words and AUTOSAR words

The course uses everyday words. This is the list that takes you from each one to the official term, and to what it means.

Plain wordAUTOSAR wordIn one sentence
Control unitECUOne of the small computers in a car.
ApplicationSoftware component (SWC)The software that does the actual function and uses the signals.
SwitchboardRTEThe layer between applications and COM.
SignalSignalOne value with a meaning, such as the speed.
PacketI-PDUA handful of bytes holding several signals side by side.
FrameL-PDUWhat the bus carries in one go.
HeartbeatMain functionCOM's regular job, called at a fixed rhythm.
Triggered / pendingTransfer propertyWhether writing a signal makes its packet go out.
Send settingTransmission modeDIRECT, PERIODIC, MIXED or NONE.
RepeatsNumber of repetitionsExtra sends after the first one.
Minimum gapMinimum delay time (MDT)Shortest allowed time between two sends of one packet.
ConditionTransmission mode condition (TMC)A rule on one signal's value used to pick the send setting.
True / false resultTransmission mode selector (TMS)The combined result of all conditions in a packet.
Immediate / deferredSignal processingWhether the application is told at once or at the next heartbeat.
Start valueInit valueThe value a signal has before a real one exists.
Update-bitUpdate-bitOne bit that marks a signal as new.
Watching the clockDeadline monitoringNoticing that a packet did not arrive, or was not sent, in time.
Reserved valueData invalid valueThe value that means "I have no good value".
FilterReception filterA pass-or-block rule for received values.
Message to the applicationNotification (callback)COM calling the application when something happened.
Signal group, memberSignal group, group signalValues that must travel as a matching set.
Staging areaShadow bufferWhere a group's values are collected before hand-over.
Packet groupI-PDU groupA set of packets started and stopped together.
Copy ruleGateway mappingA fixed rule to pass a received signal on into another packet.
Big packetLarge I-PDUA packet that does not fit in one frame.
Helper that sends in piecesTransport protocol (TP)Splits big packets into frames and joins them again.
Signal with changing sizeDynamic length signalA row of bytes whose length varies.
Fast laneLarge Data PathCOM passes finished bytes through untouched.
Sorting officePDU Router (PduR)The layer below COM that routes whole packets.
Setting, box of settingsConfiguration parameter, containerHow COM is told in advance what to do.
Byte orderEndiannessWhich byte of a longer number comes first.
Copy the signSign extensionKeeping a negative number negative when it gets more bits.
