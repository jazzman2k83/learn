Signal packing

Where a signal's bits sit in a packet (I-PDU). From lesson 16.

Bit numbering

PDU bit p is in byte p / 8, bit p % 8. Bit 0 is the LSB of byte 0. Fixed in AUTOSAR: "sawtooth" counting, "decreasing" bit order (System Template TPS_SYST_01068, TPS_SYST_01069).

Placement rules

ComSignalEndiannessComBitPosition is the…Walk
LITTLE_ENDIANsignal's LSBTowards the MSB: bit number + 1 each step.
BIG_ENDIANsignal's MSBTowards the LSB: bit number − 1 each step; from bit 0 of a byte go to bit 7 of the next byte (+ 15).
OPAQUEbit 0 of the first byte, "like in little endian byte order"Bytes copied uninterpreted; data is treated as uint8[n] and always maps to n whole bytes.

Sources: System Template Table 6.14 (startPosition) and §6.2.2; SWS COM ECUC_Com_00259, SWS_Com_00472, SWS_Com_00810.

What COM guarantees about byte order

  • Endianness conversion for all signed and unsigned integer types (SWS_Com_00007).
  • Signals and group signals are handled the same way (SWS_Com_00829).
  • Sender side: conversion happens before the I-PDU callout (SWS_Com_00221).
  • Receiver side: sign extension and conversion happen before filtering and notification (SWS_Com_00352).
