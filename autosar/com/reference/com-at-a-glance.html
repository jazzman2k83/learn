Transmission

TermSet onMeans
TRIGGEREDSignalWriting the signal makes its I-PDU go out now. Variants: only on change, with or without repetitions.2, 3
PENDINGSignalWriting it sends nothing. The value goes out with the next transmission of the I-PDU.2
DIRECTI-PDUNo period. Sent only when a TRIGGERED signal is written.2
PERIODICI-PDUSent at a fixed period only.2
MIXEDI-PDUSent at a fixed period, plus right away on a triggered write.2
NONEI-PDUCOM never starts a transmission by itself.2
Number of repetitions, repetition periodI-PDUSend the I-PDU several times after one write, this far apart.3
Minimum delay timeI-PDUShortest time between two transmissions of the same I-PDU. A transmission inside it waits.3
Transmission mode selectorI-PDUPicks ComTxModeTrue or ComTxModeFalse, from transmission mode conditions on signal values.4
Transmission deadline monitoringSignalNotification, once, if the lower layers do not confirm a transmission within the timeout.6

Reception

TermSet onMeans
IMMEDIATEI-PDUThe RTE is notified the moment the I-PDU arrives.2
DEFERREDI-PDUThe RTE is notified in the next main function (Com_MainFunctionRx).2
Init valueSignalThe value of the signal until a real one arrives.5
Update-bitSignalOne bit saying "this signal was written". Not set: the receiver ignores the signal.5
Reception deadline monitoringSignalNotification, repeated each timeout, while nothing arrives. Then keep, replace with the init value, or substitute.6
Data invalid valueSignalA configured value meaning "no valid value". The receiver notifies or replaces.7
FilterSignalA pass-or-block rule for received values. Eight filter algorithms.8
NotificationSignalReceived, timeout, invalid, transmitted, transmission timeout, transmission error.9

Order of the reception steps

  1. Restart the I-PDU's reception deadline monitoring timer
  2. Check the update-bit
  3. Convert endianness, sign extension
  4. Check for the data invalid value
  5. Filter
  6. Restart the signal's reception deadline monitoring timer
  7. Notify the RTE

Groups, gateway and large I-PDUs

TermMeans
Signal groupGroup signals that belong together are collected in a shadow buffer and handed over as one consistent set.10
I-PDU groupA set of I-PDUs that is started and stopped together, from outside COM (by BswM). All stopped after start-up.11
Signal gatewayFixed mappings that copy a received signal into I-PDUs to be transmitted, in Com_MainFunctionRouteSignals.12
Large I-PDUToo big for one frame: sent in several frames by a transport protocol below COM.13
Dynamic length signalA byte array (UINT8_DYN) whose length changes; the last signal in its I-PDU.13
Large Data PathCOM passes a finished block of bytes through without packing or keeping a copy.13
