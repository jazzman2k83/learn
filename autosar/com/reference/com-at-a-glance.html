Sending

WordSet onMeans
TRIGGEREDSignalWriting it makes the packet go out now. Flavours: only on change, with or without repeats.2, 3
PENDINGSignalWriting it sends nothing. The value rides along on the next send.2
DIRECTPacketNo timer. Sent only when a triggered signal is written.2
PERIODICPacketTimer only.2
MIXEDPacketTimer, plus right away on a triggered write.2
NONEPacketCOM never starts a send itself.2
RepeatsPacketSend the packet several times after one write.3
Minimum gapPacketPause after a send before the same packet may go again. Sends inside the pause wait.3
Two send settingsPacketA "true" and a "false" setting. Conditions on signal values pick one.4
Send timeoutSignalAlarm, once, if the bus does not confirm a send in time.6

Receiving

WordSet onMeans
IMMEDIATEPacketApplication is told the moment the packet arrives.2
DEFERREDPacketApplication is told at COM's next heartbeat.2
Start valueSignalThe value handed out until a real one arrives.5
Update-bitSignalOne bit saying "this signal is new". Not set: receiver ignores the signal.5
Receive timeoutSignalAlarm, repeating, when nothing arrives in time. Then keep, reset or substitute the value.6
Invalid valueSignalA reserved value meaning "no good value". Receiver notifies or replaces.7
FilterSignalA pass-or-block rule for received values. Eight rules.8
MessagesSignalNew value, overdue, invalid, sent, not sent in time, could not be sent.9

Order of the receiving steps

  1. Reset the packet's timeout stopwatch
  2. Check the update-bit
  3. Convert byte order and sign
  4. Check for the invalid value
  5. Filter
  6. Reset the signal's own timeout stopwatch
  7. Tell the application

Organising

FeatureMeans
Signal groupValues that belong together are collected in a staging area and handed over as one set.10
Packet groupA named set of packets that is started and stopped as a whole, from outside COM. All stopped after switch-on.11
Signal gatewayFixed rules that copy a received signal into outgoing packets, at the gateway's heartbeat.12
Big packetToo big for one frame: sent in pieces by a helper below COM.13
Changing sizeA row of bytes with varying length, last in its packet.13
Fast laneCOM passes a finished block of bytes through untouched.13
