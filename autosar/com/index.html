COM in AUTOSAR Classic

What the COM module of the AUTOSAR Classic Platform does, feature by feature, in short lessons with simulations wherever they help. It starts with the big picture and works down to configuration and bits.

How to use it. Go through the lessons in order. Each takes five to ten minutes and needs no preparation and no tools, only this browser. Some experience with AUTOSAR basic software helps, but you do not need to know COM.

Terms. The course uses the AUTOSAR terms throughout and explains each one where it is first used; each lesson ends with a table of the terms it introduces. Hover over (or tap) an underlined term to see its meaning, for example I-PDU. The Glossary lists them all.

Sheets to keep

  • COM at a glance: every feature on one page.
  • Glossary: every AUTOSAR term of the course, what it means, and the lessons that teach it.
  • COM's interfaces: every module COM talks to, and every function between them.
  • Signal packing: the bit-level cheat sheet.

When you configure COM yourself

  • Configuration help: a configurator that turns answers about the wanted behaviour into COM parameters, a recipe book and a troubleshooting guide.

Facts are checked against the AUTOSAR Classic Platform specifications, release R25-11, mainly the Specification of Communication. Timings in the simulations are slowed down so you can watch them; real systems work in milliseconds.
