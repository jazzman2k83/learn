AUTOSAR COM

The signal gateway

An ECU connected to two buses can pass a value from one to the other. COM can do this by itself, without any SWC in between.

Copy a signal from one I-PDU to another

The engine ECU sends the speed on bus A. A display on bus B needs it too. The ECU in the middle is configured once: "whenever this signal arrives, copy it into that signal of that outgoing I-PDU". That is the signal gateway (the COM function that copies a received signal into an I-PDU to be transmitted, without any SWC in between). Each such route is one ComGwMapping (one source signal and one or more destination signals).

  • It works on single signals, so the two I-PDUs can look completely different.
  • One received signal can be copied into several outgoing I-PDUs.
  • The routes are fixed in the configuration. They do not depend on the values.

After the copy, everything is as usual

For the outgoing I-PDU, a copy by the signal gateway counts exactly like a write by the RTE. So everything from lessons 2 to 4 applies: the transfer property of the destination signal, the transmission mode of its I-PDU, the minimum delay time.

The signal gateway does not copy in the very moment an I-PDU arrives. It has its own main function, Com_MainFunctionRouteSignals, and does all waiting copies in its next call. This keeps the reception itself short and fast.

Try it

Let I-PDUs arrive on bus A. Com_MainFunctionRouteSignals, shown as "Main function", runs every 2 seconds.

Three rules worth knowing

Only new values

If the received signal has an update-bit and it is not set, nothing is copied.

Timeouts do not block

Even after a timeout of reception deadline monitoring, a value that arrives is still copied.

Byte order is converted

If source and destination signal have a different endianness (byte order: which byte of the value comes first), COM converts on the way.

Not the only gateway. If a whole I-PDU should go from bus A to bus B unchanged, COM is not needed at all. The PduR below COM forwards whole I-PDUs, which is cheaper. The signal gateway is for when the I-PDUs differ.

New terms in this lesson

TermMeaning
signal gatewayThe COM function that copies a received signal or signal group into an I-PDU to be transmitted, without any SWC in between.
ComGwMappingOne route of the signal gateway: one source signal and one or more destination signals.

Source: AUTOSAR COM specification, R25-11, sections 7.1.5 and 7.10 (SWS_Com_00377, 00359, 00466, 00360, 00701, 00703, CONSTR_00598). Finer points: group signals can be routed too, and stay consistent. Signals in large I-PDUs, which travel through a transport protocol (lesson 13), cannot be routed this way.
