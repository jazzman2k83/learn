AUTOSAR COM

Transmission mode selection

An I-PDU can have two transmission modes, for example fast and slow. COM picks one by looking at the values of the signals inside the I-PDU.

Why two?

Some information matters more in one situation than another. While the car is moving, the speed should be sent often. While it stands still, once in a while is enough, and the bus stays free for other things.

So every I-PDU can have two transmission modes, one for TRUE and one for FALSE. Each one is a full transmission mode from lesson 2: DIRECT, PERIODIC, MIXED or NONE, with its own period.

used while the selection is TRUE

Transmission mode TRUE

For example: PERIODIC, every second.

used while the selection is FALSE

Transmission mode FALSE

For example: PERIODIC, every four seconds. Or NONE: no transmission at all.

Who decides?

A condition on a signal's value, such as "speed is not 0". AUTOSAR calls it a transmission mode condition (TMC: a condition on one signal of the I-PDU, with the result true or false). The condition is a filter (a rule on a signal value with a true or false result; lesson 8 shows all kinds) configured for that signal. COM evaluates it every time the SWC writes that signal.

COM combines the results of all TMCs of the I-PDU into one result, the transmission mode selector (TMS: the result that picks one of the two transmission modes):

  • Several signals in the I-PDU may each have a TMC. If at least one is true, the TMS is TRUE and transmission mode TRUE is used.
  • If none is true, the TMS is FALSE and transmission mode FALSE is used.
  • If no signal has a TMC, the TMS is always TRUE, so the I-PDU simply always uses transmission mode TRUE. That is the normal, simple case.

When the TMS changes, COM uses the new transmission mode at once and restarts its period. If the new transmission mode is PERIODIC or MIXED, the first transmission goes out right away (as far as the minimum delay time allows), so the receivers learn about the change without waiting.

Try it

The TMC is "speed is not 0". Transmission mode TRUE is PERIODIC, every second. Start the car, stop it, and watch the rhythm of the I-PDUs change.

Things to notice. Each change of the TMS causes one I-PDU right away, if the new transmission mode is PERIODIC. Writing the same speed again changes nothing, because the TMC result did not change.

Nothing is thrown away. The TMC only chooses the transmission mode. COM never drops a value on the sending side. Dropping unwanted values is something only a receiver does, with the same kinds of filter. That is lesson 8.

New terms in this lesson

TermMeaning
transmission mode condition (TMC)A filter on one signal of an I-PDU. Its result, true or false, feeds the transmission mode selector.
transmission mode selector (TMS)The result that picks the transmission mode of an I-PDU: TRUE if at least one TMC is true (or if there is no TMC), otherwise FALSE.

Source: AUTOSAR COM specification, R25-11, section 7.2.3.2 (SWS_Com_00676 to 00679, 00245, 00032, 00799, 00239, 00244, 00495).
