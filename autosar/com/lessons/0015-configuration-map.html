AUTOSAR COM

The configuration map

Everything COM does is decided in advance, in its configuration. This lesson shows where each feature from the course lives in that configuration, and under which name.

COM has no code for your vehicle

The COM software is the same in every ECU. What makes it fit one ECU is its configuration: which I-PDUs exist, where each signal sits, which signals are TRIGGERED, which timeouts apply. None of this is decided while the vehicle runs.

The configuration is usually not typed by hand. The vehicle manufacturer describes the whole network in a system description (an ARXML file with all ECUs, buses, I-PDUs and signals of the vehicle), and a tool derives the COM configuration of each ECU from it. Still, when something behaves oddly, the configuration is where you look.

The shape of the configuration

The configuration is a tree of containers (named groups of settings; a container can hold other containers). Each container holds parameters (single settings, for example ComTransferProperty). This is the part of the tree that matters for this course, with the course term on the right.

  • ComConfig the whole COM configuration
    • ComIPdu one I-PDU
      • ComTxIPdu extra parameters of a sent I-PDU
        • ComTxModeTrue → ComTxMode transmission mode for TRUE
        • ComTxModeFalse → ComTxMode transmission mode for FALSE
    • ComSignal one signal
      • ComFilter its filter, or its transmission mode condition
    • ComSignalGroup one signal group
      • ComGroupSignal one group signal
    • ComIPduGroup one I-PDU group
    • ComGwMapping one mapping of the signal gateway
      • ComGwSource the source signal
      • ComGwDestination a destination signal

An I-PDU does not contain its signals in this tree. Its ComIPdu container (the configuration of one I-PDU) refers to them, and each ComSignal container (the configuration of one signal) says at which bit of the I-PDU the signal sits.

How to read a parameter name

The names look long but follow a pattern. They start with Com, then say what they belong to, then what they set. ComTxModeTimePeriod is: COM, transmission mode, time period. ComRxDataTimeoutAction is: COM, received data, action on timeout. Read them from left to right and most explain themselves.

When you have to do it yourself

For real configuration work there are three helpers: a configurator that turns answers about the wanted behaviour into parameters and values, a recipe book for typical jobs, and a troubleshooting guide.

New terms in this lesson

TermMeaning
system descriptionThe ARXML file in which the vehicle manufacturer describes the whole network; the COM configuration of each ECU is derived from it.
containerA named group of parameters in the configuration, for example ComIPdu or ComSignal. Containers can hold other containers.
parameterOne setting inside a container, for example ComTransferProperty.
ComIPduThe container of one I-PDU: direction, signal processing, transmission modes, I-PDU groups and its signals.
ComSignalThe container of one signal: position, size, type, transfer property, init value, filter, timeouts and notifications.

Source: AUTOSAR COM specification, R25-11, chapter 10 (configuration specification). Only the parameters needed for this course are shown; the specification lists them all.
