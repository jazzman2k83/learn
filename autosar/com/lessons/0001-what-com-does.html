AUTOSAR COM

What COM does

COM is the AUTOSAR module that moves values between ECUs (the computers in a car). The software of one ECU hands COM single values. COM sends them to the other ECUs and brings their values back.

The problem COM solves

A car has many small computers, the ECUs (Electronic Control Units). They talk over a shared network, the bus (the wiring that connects the ECUs). On most cars that is CAN (Controller Area Network); newer ones also use Ethernet (the IP-based network).

The software inside an ECU is made of SWCs (software components: the application software that works with the values). They do not call COM themselves. The RTE (Runtime Environment: the layer between the SWCs and the basic software below) passes their values to COM and back.

An SWC thinks in single values: the speed, a temperature, "door open". Each one is a signal (one value with a meaning). The bus does not carry single values. It carries blocks of bytes. The block COM works with is the I-PDU (Interaction Layer Protocol Data Unit: a block of bytes that holds several signals side by side). Somebody has to translate between signals and I-PDUs, and decide when each I-PDU is sent. That somebody is COM. As a comparison: COM works like a mail room that puts many letters into one bag and sends the bag off.

What COM does not do. COM does not know which bus it is on. It hands every I-PDU to one module below it, the PduR (PDU Router: the module that forwards I-PDUs between COM and the modules for each bus), and receives I-PDUs from it. Everything specific to CAN or Ethernet happens further down. Lesson 14 shows the layers below COM.

New terms in this lesson

TermMeaning
COMThe Communication module of the AUTOSAR Classic Platform. It packs signals into I-PDUs, decides when they are sent, and unpacks received I-PDUs into signals again.
ECUElectronic Control Unit: one of the computers in a car.
busThe shared network that connects ECUs, for example CAN or Ethernet.
CANController Area Network: the most common vehicle bus.
EthernetThe IP-based vehicle network.
SWCSoftware component: application software that writes and reads signals.
RTERuntime Environment: the layer between the SWCs and the basic software. It calls COM to send and receive signals.
signalOne value with a meaning, for example the speed.
I-PDUInteraction Layer Protocol Data Unit: a block of bytes that holds several signals side by side. COM sends and receives whole I-PDUs.
PduRPDU Router: the module below COM. It forwards I-PDUs between COM and the modules for each bus.
