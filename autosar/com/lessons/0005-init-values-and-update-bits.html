AUTOSAR COM

Init values and update-bits

Two small features for received signals. The init value answers "what does a read give before anything was received?". The update-bit answers "is this value really new?".

Init values

After start-up, an SWC may read a signal before any I-PDU has been received. COM must still answer. So every signal has an init value (the value a signal has from start-up until a real value is received or written), chosen in the configuration. COM returns it until a received value replaces it.

The same is true on the sending side: if an I-PDU is transmitted before the SWC has written every signal in it, the missing ones go out with their init values.

Update-bits

An I-PDU always carries all of its signals. Suppose an I-PDU holds Speed and Temperature and is transmitted because Speed was written. Temperature goes along, unchanged. The receiver cannot tell whether that temperature is fresh or the same old one again.

An update-bit (one extra bit in the I-PDU that belongs to one signal and means "this signal was written since the last transmission") solves this.

sender

Set and clear

COM sets the bit when the SWC writes the signal, and clears it again after the I-PDU was transmitted.

receiver

Check

Bit set: COM handles the signal as usual. Bit not set: COM ignores this signal completely, as if it had not been in the I-PDU.

The SWC never sees the bit. COM handles it on both sides.

New terms in this lesson

TermMeaning
init valueThe value a signal has from start-up until a real value is received or written.
update-bitOne bit in an I-PDU next to a signal: set by the sender when the signal was written, checked by the receiver, which ignores the signal if the bit is not set.

Source: AUTOSAR COM specification, R25-11, sections 7.2.1.4 and 7.9 (SWS_Com_00098, 00228, 00061, 00062, 00324, 00802). Finer points: a setting chooses when the sender clears the update-bits: right after handing the I-PDU to the PduR, after the transmission was confirmed, or when a lower layer fetched the I-PDU content. A signal group (a set of signals sent and received as one consistent set, lesson 10) gets one update-bit for the whole group. All update-bits start cleared.
