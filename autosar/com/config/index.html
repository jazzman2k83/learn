Three things to know first

  • Times are in seconds. Every time in COM's configuration is a decimal number of seconds. 100 ms is 0.1.
  • COM counts time in main function calls. Choose periods, the minimum delay time and timeouts as multiples of the period of the main function.
  • Some parameters belong to the I-PDU, some to the signal. The transmission mode with its period and number of repetitions, and the minimum delay time are set once per I-PDU. The transfer property (TRIGGERED or PENDING), the timeout and the init value are set per signal.

What these tools cover. Only COM's own configuration parameters, with the standard names of AUTOSAR release R25-11. They do not cover the layers below COM (PduR, CanIf, SoAd …), and they do not describe the screens of any vendor's configuration tool. Vendors add their own parameters and may name a few things differently, mostly in older releases. Treat the output as something to compare with, not as a finished file.

Checked against the AUTOSAR COM specification, R25-11, chapters 7 and 10, and the Specification of ECU Configuration, R25-11 for the ARXML form.
