Three things to know first

  • Times are in seconds. Every time in COM's configuration is a decimal number of seconds. 100 ms is 0.1.
  • COM counts time in heartbeats. Choose periods, gaps and limits as multiples of the heartbeat period.
  • Some settings belong to the packet, some to the signal. The timer, the repeats and the minimum gap are set once per packet. Triggered or pending, the timeout and the start value are set per signal.

What these tools cover. Only COM's own settings, with the standard names of AUTOSAR release R25-11. They do not cover the layers below COM, and they do not describe the screens of any vendor's configuration tool. Vendors add their own settings and may name a few things differently, mostly in older releases. Treat the output as something to compare with, not as a finished file.

Checked against the AUTOSAR COM specification, R25-11, chapters 7 and 10, and the Specification of ECU Configuration, R25-11 for the ARXML form.
