AUTOSAR COM · Configuration help

Recipe book

Typical jobs and the settings that do them. Each recipe shows only the settings that matter for the job, what to watch out for, and the same thing as ARXML.

How to read a recipe. The table lists the settings to change. Every signal and packet also needs the basic settings from the first recipe. Times are in seconds: 100 ms is 0.1. Where a recipe has a link to the configurator, it opens with the recipe filled in, so you can change the numbers to yours.

    Names, values and rules: AUTOSAR COM specification, R25-11, chapters 7 and 10. Advice marked as common practice is not from the specification. Messages to the application are set in the configuration of COM's user (ComUserCallback); in projects on older releases they sit on the signal itself, for example as ComNotification.
