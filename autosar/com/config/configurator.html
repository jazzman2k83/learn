      Messages to the application

      Messages are not set in COM itself. They are set in the configuration of whoever uses COM, normally the switchboard (RTE), in a box called ComUserCallback. The signal is linked to it with ComUserCallbackRef.

      What this tool does not know. It looks at one signal in one packet. It cannot see the other signals in the packet, the layers below COM, or the extra settings your tool vendor adds. Handle numbers are left out because tools assign them. Names follow AUTOSAR release R25-11. In projects on older releases the messages are set on the signal itself, with names such as ComNotification and ComTimeoutNotification.
