Network and Mode Management in AUTOSAR Classic

Network Management

Configuration help

Reference material for the engineer doing the configuration work: typical jobs step by step, and the way from a symptom on the bus to the setting that causes it.

when you change a configuration

Recipe book

Typical jobs in order: add a CAN channel with NM, add a PNC, wake on CAN with validation, keep a channel awake for diagnostics, coordinate two buses on a gateway, migrate PNC handling from COM signals to NmIf. Each with the parameters to set, the rules to check and the lessons behind it.

when something does not work

Troubleshooting guide

From symptom to cause: the bus never sleeps, the ECU does not wake up, the wakeup expires, a PNC stays requested, bus-off loops, the channel goes down too early. Plus how to read a configuration you did not write, in the R25-11 form and in the older 4.4.0 and R20-11 form.

Both pages use the same parameter list as the configuration maps of lesson 55 and lesson 56: every container and parameter name, its place, its multiplicity and the lesson that explains the feature come from one source. Projects on older releases find renamed and moved parameters on the sheet Release differences.

Source: chapter 10 (configuration specification) of the R25-11 specifications of ComM, Network Management Interface, CAN Network Management, UDP Network Management, CAN State Manager, Ethernet State Manager, ECU State Manager, CAN Interface and Dcm; for the older form the same documents of 4.4.0 and R20-11. Configuration tool screens are left out: they differ from tool to tool.
