Network and Mode Management in AUTOSAR Classic

How an ECU of the AUTOSAR Classic Platform wakes up, keeps its buses awake exactly as long as someone needs them, coordinates them with the other ECUs and goes back to sleep: ComM, network management, the bus state managers, EcuM, BswM and partial networking.

How to use it. Go through the 58 lessons in order. Each takes a few minutes and needs only this browser. Many lessons have a state machine to drive, a timer to watch or a call sequence to step through.

Terms. The course uses the AUTOSAR terms throughout and explains each one where it is first used; each lesson ends with a table of the terms it introduces. Hover over (or tap) an underlined term to see its meaning, for example bus sleep. The Glossary lists them all.

You should know the basics of the AUTOSAR basic software (BSW): layers, modules, I-PDUs. The COM course covers I-PDUs, the PDU Router and I-PDU groups; this course builds on it.

Release. The course follows release R25-11. Where 4.4.0 or R20-11 behave differently, an "Older releases" box says so. Part 10 teaches the older ways in full: EcuM Fixed (4.3.1 and older) and partial networking through COM signals (up to R20-11).

Sheets to keep

  • At a glance: every module and feature on one page, with the lesson that explains it.
  • Glossary: every AUTOSAR term of the course, what it means, and the lessons that teach it.
  • Interfaces: who calls whom, module by module.
  • NM timers: every network management timer on one sheet.
  • The older and the newer way: EcuM Fixed and EcuM Flex, PNC through COM and through NmIf, side by side.
  • Release differences: what is different in 4.4.0 and R20-11.
  • FlexRay and LIN: how the other buses fit the same picture.

Facts are checked against the AUTOSAR specifications of release R25-11: the module specifications of ComM, Network Management Interface, CAN Network Management, UDP Network Management, CAN State Manager, Ethernet State Manager, ECU State Manager, BSW Mode Manager, CAN Interface, CAN Transceiver Driver, Ethernet Interface and Dcm, plus the Layered Software Architecture; for the older ways, the same documents of 4.2.2 to R24-11 and the specification of the ECU State Manager with fixed state machine (4.3.1). Each lesson names its source. Timings in the interactive parts are scaled so you can watch them.
