Network and Mode Management in AUTOSAR Classic

Network Management

Power on to full communication

The body gateway is switched on. From the reset to the first NM PDU on body CAN, EcuM starts the ECU, BswM allows communication, and a request of UserComfort travels through ComM, CanSM and CanNm until BswM starts the I-PDU groups.

This is the first of four complete flows on the example ECU of lesson 3. Every call, its caller and its order are taken from the R25-11 specifications; where they leave a choice to the integrator, the step says so. The flow puts together what lessons 4, 9, 21, 26 and 27 taught one piece at a time.

The starting point

The battery has just been connected: a power-on reset. Nothing runs yet; there is no OS, no scheduler, no RTE. All three buses sleep. The wakeup source of this start is ECUM_WKSOURCE_POWER, which EcuM derives from the reset reason. The SWC BodyControl will request the Comfort functions as soon as it runs.

The four phases

EcuM · lesson 26

From reset to BswM

EcuM_Init runs the StartPreOS Sequence and starts the OS. The first task calls EcuM_StartupTwo, which starts the SchM and initializes BswM. From here on the UP phase runs, and BswM is in charge.

BswM · lessons 9, 27

Initialize, allow, start

BswM's action list entries initialize the rest of the BSW, start the RTE and set communication allowed with ComM_CommunicationAllowed. Which rule does what, and in which order, is the integrator's configuration.

ComM · lessons 4, 6, 41

The request

ComM_RequestComMode only stores the request. In ComM_MainFunction_BodyCan the PNC Comfort enters COMM_PNC_REQUESTED, the channel enters COMM_FULL_COMMUNICATION, and ComM calls CanSM first, then Nm_NetworkRequest.

CanSM, CanNm · lessons 13, 21

Bus up, mode back up

CanSM starts transceiver and controller and reports COMM_FULL_COMMUNICATION; CanNm enters the Repeat Message State and sends the first NM PDU. BswM, told by ComM, starts the I-PDU groups.

What the specification leaves to the integrator

EcuM fixes the order up to BswM_Init. Everything after that is configuration:

  • Which BSW modules BswM initializes, in which order, and when it starts the RTE. EcuM Flex only says that this "becomes code executed in the BswM's action lists". ComM must be initialized after NvM; CanNm after CanIf and the LSduR; the rest follows from such notes in each specification.
  • When BswM calls ComM_CommunicationAllowed with TRUE, and for which channel entries. Until then ComM keeps a requested channel in COMM_NO_COM_REQUEST_PENDING; its default after initialization is "not allowed".
  • Whether a BswM rule is evaluated at once in the caller's context or later in BswM_MainFunction; that is set per mode request.
  • Which I-PDU groups the rules start, on which mode: per channel, per PNC, or both.

The order of the SWC's request and BswM's permission does not matter: if the request comes first, the channel simply waits in COMM_NO_COM_REQUEST_PENDING until communication is allowed.

The other two buses

PNC Comfort also uses Eth, so the same main function work runs in ComM_MainFunction_Eth: ComM calls EthSM_RequestComMode and Nm_NetworkRequest for Eth, NmIf passes it on as UdpNm_NetworkRequest, and EthSM brings the link up (lesson 23). Chassis CAN stays asleep: no user needs it yet, and nothing in NmIf ties it to the other buses. The gateway has no NM coordinator, because it uses partial networking in NmIf (lesson 3); even a coordinator would keep only buses awake that are already awake (lesson 37).

The start-up sequence of EcuM Flex is the same in 4.4.0 and R20-11. Two details of this flow differ. In 4.4.0 and R20-11 CanNm calls CanIf_Transmit directly; the LSduR between them exists from R24-11. And up to R20-11 ComM did not use Nm_UpdateIRA: the Comfort bit reached the NM PDU through a COM signal (lesson 53). With EcuM Fixed (4.3.1 and older), EcuM itself allowed communication on entering RUN (lesson 51).

Things to notice. EcuM drives only the first part; once BswM_Init has run, the order is the integrator's. Nothing on the bus moves before BswM allows communication, however early the SWC asks. The way down (ComM to CanSM and NmIf) and the way back up (indications from CanSM and CanNm) are separate, and BswM, not ComM, starts the I-PDU groups.
