Network and Mode Management in AUTOSAR Classic

Network Management

Passive mode, communication control, bus load reduction

Three optional features change when a node sends its NM PDUs: one node never sends, one stops sending for a while on request, and many nodes together send fewer.

The algorithm of lessons 12 to 14 assumes that every node sends NM PDUs while it needs the bus. These three features change that rule, each for a different reason. All of them are configured per node; none changes the states themselves.

Passive mode

In passive mode (an NM configuration in which the node receives NM PDUs but never sends one) a node follows the bus without influencing it. It is woken when the others wake the bus, stays in Network Mode while their NM PDUs arrive, and goes to sleep with them. It can never keep the bus awake, and it cannot request the network: NmIf refuses a network request on such a channel. ComM's NM variant PASSIVE (lesson 8) is the ComM side of a channel whose NM runs in passive mode.

Because a passive node never sends, everything that depends on its own NM PDUs is left out: node detection, the detection of remote sleep (lesson 18) and bus synchronization for the coordinator. Passive mode is either on or off for all NM channels of one ECU.

Communication control

Communication control (switching off the sending of NM PDUs on a channel for a while without leaving Network Mode) exists for diagnostics. A tester sends the diagnostic service CommunicationControl to the ECU. Dcm reports the new communication mode to BswM, and a BswM rule calls NmIf, which passes the call to the NM of that channel:

While sending is disabled, CanNm stops its message cycle, so no NM PDUs leave the node. It also stops its NM-Timeout Timer and the detection of remote sleep, and a received NM PDU no longer restarts the timer. The node therefore stays in Network Mode, silent, whatever the other nodes do. When sending is enabled again, the first NM PDU goes out within the next main function and the NM-Timeout Time starts again.

Communication control does not change the length of Repeat Message State, and it is only accepted in Network Mode. Dcm switches communication back on by itself when the diagnostic session ends or changes to one that does not support the service.

Bus load reduction

Every node of a bus uses the same Message Cycle Time. Without help, ten nodes in Normal Operation State put ten NM PDUs on the bus per cycle. A node-specific cycle offset only spreads them out; it does not reduce them. Bus load reduction (an optional mechanism that keeps at most two nodes sending NM PDUs in Normal Operation State) uses two rules:

  • After sending an NM PDU, a node waits one Message Cycle Time until its next one.
  • After receiving an NM PDU, a node restarts its wait with its own reduced time, a node-specific value greater than half the Message Cycle Time and less than a whole one.

The node with the smallest reduced time always comes first after a received PDU, so only the two nodes with the smallest reduced times keep sending, in turn. If one of them stops, the node with the next smallest reduced time takes its place. A node that is alone sends one NM PDU per Message Cycle Time. Bus load reduction is only active in Normal Operation State; entering Repeat Message State switches it off, so that every node is seen there.

Try it

Three nodes of body CAN with a Message Cycle Time of 1 s; reduced times: gateway 0.6 s, Door ECU 0.7 s, Light ECU 0.8 s; Repeat Message Time 2 s, NM-Timeout Time 2.5 s. Times are scaled up so that you can follow them. Press Start, then switch the features while the clock runs.

    Things to notice. With bus load reduction on, the Light ECU stays silent although it needs the bus: the NM PDUs of the others keep restarting its NM-Timeout Time, which is all it needs. Disable the gateway's NM PDUs and the Light ECU starts sending in its place. A passive Light ECU never sends, even when it would be its turn. And a gateway with communication control active does not fall asleep with the others, because its NM-Timeout Time is stopped.
