What's new

Changes to this course, newest first.

25 Nov 2026

  • New Configuration help: a recipe book of eight typical configuration jobs (add a CAN channel with NM, add a PNC, wake on CAN with validation, keep a channel awake for diagnostics, coordinate two buses, move PNC handling from COM signals to NmIf, add an Ethernet channel, set the NM timers) and a troubleshooting guide from symptom to cause, including how to read a configuration you did not write.
  • Fixed Since R21-11 the network management interface supports either the NM coordinator or partial networking, not both. The example gateway uses partial networking, so lesson 3, lesson 48, lesson 49 and lesson 55 now show it without the NM coordinator, and lessons 37–39 say which configuration they show.
  • Changed Lesson 55 and lesson 56 use the same parameter list as the configuration help.
  • New the course, with 58 lessons in 12 parts: the big picture, ComM, network management, the bus state managers, EcuM and BswM, wakeup, the NM coordinator, partial networking, four flows end to end, the older way (EcuM Fixed, PNC through COM signals), configuration maps and the low-level details.
  • New a CAN simulator of ComM, CanNm and CanSM with the NM timers, used in several lessons (for example lesson 14 – The NM timers).
  • New reference sheets At a glance, Interfaces, NM timers, The older and the newer way, Release differences, FlexRay and LIN and the Glossary.
