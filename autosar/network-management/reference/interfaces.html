ComM

ComM is the only module that the ComM users talk to, and the only one that requests communication modes from the bus state managers.

ComM calls Nm_NetworkRequest, Nm_NetworkRelease and Nm_PassiveStartUp (NmIf), CanSM_RequestComMode and EthSM_RequestComMode, Nm_UpdateIRA, the Dcm and BswM functions below, and switches the mode of each user through the mode switch port UM_{user_name}.

The mode indication is written ComM_CanSM_ModeIndication here, as in the R25-11 ComM specification (ComM_<Bus>SM_ModeIndication). The R25-11 CanSM specification and all releases up to R24-11 write ComM_BusSM_ModeIndication; it is the same function. Nm_UpdateIRA, ComM_Nm_UpdateEIRA and ComM_Nm_UpdateERA are new in R21-11 (draft) and valid from R22-11; before, ComM read EIRA and ERA as COM signals (53).

RTE

The SWC BodyControl never calls a BSW module directly. Its ports go through the RTE: to ComM through UR_{user_name} (requests) and UM_{user_name} (the mode switch port of each user), to EcuM for RUN and POST_RUN requests and the alarm clock, to NmIf for user data. Lessons 5, 28, 31.
