Network and Mode Management in AUTOSAR Classic

Network Management

Differences between releases

The course follows release R25-11. Many ECUs still run on 4.4.0 or R20-11, and some on 4.3.1 or older with EcuM Fixed. The state machines of ComM, CanNm and CanSM work the same in all of them; what moved is mainly partial networking, a few EcuM functions and where some configuration parameters live. This sheet lists every difference that touches the course, module by module.

The same in 4.4.0, R20-11 and R25-11

These parts of the course work the same in all three releases: the ComM users and channels, the channel state machine with its sub-states, communication allowed, the Dcm interface (ComM_DCM_ActiveDiagnostic), communication inhibition (apart from what is stored over a reset, below); the CanNm states, the NM timers, node detection, passive mode and Remote Sleep Indication; the CanSM states and bus-off recovery; the wakeup sources and wakeup validation through CanIf_CheckValidation; passive wakeup on a coordinated channel; nested sub-buses and the NM Coordinator Sleep Ready Bit; the PNC state machine and the rule for the byte and bit of a PNC. Some rules only moved: from R25-11 on, CanNm refers to the NM protocol specification for the immediate transmissions and the Wait Bus-Sleep Time instead of stating them itself, without a change in behaviour.
