NM timers

Every timer that decides when a bus wakes, stays awake or falls asleep, on one sheet: what it does, which module runs it, its configuration parameter, the rule that limits it, and the lesson that explains it. At the end, a calculator for the four CanNm timers.

CanNm and UdpNm

CanNm and UdpNm use the same timers; only the prefix of the parameter changes (CanNm… or UdpNm…, in CanNmChannelConfig or UdpNmChannelConfig). All values are in seconds. The rules marked "same in the cluster" must have the same value in every node of the NM cluster.

The rule that ties them together (Foundation NM protocol, PRS_Nm_00506 and PRS_Nm_00115): with the network released, a node enters Bus-Sleep Mode when no NM PDU has been on the bus for the NM-Timeout Time plus the Wait Bus-Sleep Time. UdpNm has no bus load reduction and no CanNmMsgReducedTime.

Try it: when does the bus sleep?

Enter the four CanNm timers of one channel, in seconds. The sheet applies the rule of the NM protocol: Bus-Sleep Mode follows the last NM PDU on the bus after the NM-Timeout Time plus the Wait Bus-Sleep Time. The bar shows a node that was woken by another node, which then fell silent, and that nobody needs: it stays in the Repeat Message State, sends its NM PDUs, and then falls asleep. Immediate transmissions and the offset are left out (offset 0).

    The middle line depends on where the release falls in the cycle: the node's last NM PDU went out up to one Message Cycle Time before the release, and the NM-Timeout Time counts from that NM PDU. The last line counts the NM PDUs of the Repeat Message State at 0, 1, 2 … Message Cycle Times; the last one is the one before the Repeat Message Time runs out.

    Things to notice. Only the NM-Timeout Time and the Wait Bus-Sleep Time decide how long a quiet bus stays awake, and both must be the same in every node so that the nodes fall asleep together. The Message Cycle Time sets how often a node that needs the bus says so; the Repeat Message Time is the shortest stay after a wakeup. The ComM and NmIf timers sit on top: they delay the release (ComM LIGHT and minimum duration, the NM coordinator's shutdown timers), they never shorten the bus NM's own way to sleep.
