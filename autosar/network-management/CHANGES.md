# Changes

## 2026-11-25
- New: [Configuration help](config/index.html): a [recipe book](config/recipes.html) of eight typical configuration jobs (add a CAN channel with NM, add a PNC, wake on CAN with validation, keep a channel awake for diagnostics, coordinate two buses, move PNC handling from COM signals to NmIf, add an Ethernet channel, set the NM timers) and a [troubleshooting guide](config/troubleshooting.html) from symptom to cause, including how to read a configuration you did not write.
- Fixed: Since R21-11 the network management interface supports either the NM coordinator or partial networking, not both. The example gateway uses partial networking, so [lesson 3](lessons/0003-the-example-ecu.html), [lesson 48](lessons/0048-woken-by-another-ecu.html), [lesson 49](lessons/0049-going-to-sleep.html) and [lesson 55](lessons/0055-configuration-map-comm-and-nm.html) now show it without the NM coordinator, and [lessons 37–39](lessons/0037-coordinating-several-buses.html) say which configuration they show.
- Changed: [Lesson 55](lessons/0055-configuration-map-comm-and-nm.html) and [lesson 56](lessons/0056-configuration-map-state-managers-and-ecum.html) use the same parameter list as the configuration help.
- New: the course, with 58 lessons in 12 parts: the big picture, [ComM](lessons/0005-comm-users-and-channels.html), [network management](lessons/0012-the-coordination-algorithm.html), the [bus state managers](lessons/0021-cansm-the-state-machine.html), [EcuM and BswM](lessons/0025-the-ecum-phases.html), [wakeup](lessons/0033-wakeup-sources-and-their-states.html), the [NM coordinator](lessons/0037-coordinating-several-buses.html), [partial networking](lessons/0040-why-partial-networking.html), [four flows end to end](lessons/0047-power-on-to-full-communication.html), [the older way](lessons/0051-ecum-fixed.html) (EcuM Fixed, PNC through COM signals), configuration maps and the low-level details.
- New: a CAN simulator of ComM, CanNm and CanSM with the NM timers, used in several lessons (for example [lesson 14 – The NM timers](lessons/0014-the-nm-timers.html)).
- New: reference sheets [At a glance](reference/at-a-glance.html), [Interfaces](reference/interfaces.html), [NM timers](reference/nm-timers.html), [The older and the newer way](reference/older-and-newer-way.html), [Release differences](reference/release-differences.html), [FlexRay and LIN](reference/flexray-and-lin.html) and the [Glossary](reference/words.html).
