The Initial Wait Phase, Repetition Phase and Main Phase of server and client, and every Sd timer that shapes them, on one page.

Server timers (SdServerTimer)

The SdServerTimer container of an SdServerService; the PRS constant each parameter sets is named in brackets.

ParameterEffectLesson
SdServerTimerInitialOfferDelayMin / …Maxrandom wait of the Initial Wait Phase before the first OfferService (INITIAL_DELAY_MIN / INITIAL_DELAY_MAX)12
SdServerTimerInitialOfferRepetitionBaseDelayfirst gap of the Repetition Phase; each gap doubles (REPETITIONS_BASE_DELAY)12
SdServerTimerInitialOfferRepetitionsMaxnumber of repeated OfferService entries; 0 skips the phase (REPETITIONS_MAX)12
SdServerTimerOfferCyclicDelayperiod of the OfferService in the Main Phase; 0 = no cyclic OfferService (CYCLIC_OFFER_DELAY)12
SdServerTimerRequestResponseMinDelay / …Maxrandom wait before answering a multicast FindService (REQUEST_RESPONSE_DELAY)13
SdServerTimerTTLTTL of each OfferService, in seconds; 0xFFFFFF = until the next reboot11
