SOME/IP in AUTOSAR Classic

How ECUs of the AUTOSAR Classic Platform offer and use services over Ethernet: what SOME/IP does, how Service Discovery brings client and server together, and how one message travels between the Ethernet wire and the software component.

How to use it. Go through the 32 lessons in order. Each takes a few minutes and needs only this browser. Many lessons have something to click or step through.

Terms. The course uses the AUTOSAR terms throughout and explains each one where it is first used; each lesson ends with a table of the terms it introduces. Hover over (or tap) an underlined term to see its meaning, for example eventgroup. The Glossary lists them all.

You should know the basics of the AUTOSAR basic software (BSW): layers, modules, PDUs. You do not need to know Ethernet, IP or SOME/IP.

Sheets to keep

  • SOME/IP at a glance: every feature on one page, with the lesson that explains it.
  • Glossary: every AUTOSAR term of the course, what it means, and the lessons that teach it.
  • IDs, types and codes: message types, return codes, reserved IDs, SD entry and option types.
  • Service Discovery timing: the phases and every timer on one sheet.

Facts are checked against the AUTOSAR specifications of release R20-11: the SOME/IP and SOME/IP Service Discovery protocol specifications and the module specifications of Service Discovery, SOME/IP Transformer, SOME/IP Transport Protocol, Socket Adaptor, TCP/IP, Ethernet Interface, Ethernet Driver, PDU Router, COM, Large Data COM and RTE, plus the System Template. Each lesson names its source. Timings in the interactive parts are slowed down so you can watch them; real systems work in milliseconds.
